핵심 단어 비교

가장 많이 혼용되는 용어

✅ 공식 — 한국어
타입
성향·성격 느낌. "내 타입"처럼 쓸 수 있음.
"Claude 타입이 뭐야?"
"내 타입은 GPT야."
"4개 타입 중 하나를 배정받아요."
❌ 구버전 — 쓰지 말 것
진영 / 하우스
군사·정치적(진영) 또는 구버전(하우스) 표현. 리브랜딩으로 타입으로 교체됨.
"Claude 진영이 뭐야?" ❌
"내 하우스는 GPT야." ❌
"4개 진영 중 하나." ❌
✅ 공식 — 영어
Type
성향·성격 유형 의미. 직관적이고 바이럴에 유리.
"Which type are you?"
"I'm Claude Type."
"Find your AI type."
❌ 구버전 — 쓰지 말 것
Faction / House
분열·대립(Faction) 또는 구버전(House) 표현.
"Which faction are you?" ❌
"I'm in the Claude House." ❌
💡 예외: SEO 키워드로는 "진영" "faction" "house"를 메타 keywords에 병기해도 됨. 구글 검색에서 "AI 진영 테스트"로 유입되는 트래픽을 놓치지 않기 위함.

Chapter 6
코드 내부 예외 — 변경 불필요

코드 안에서는 "faction" 그대로 유지해도 됨

사용자 눈에 보이지 않는 코드 내부 변수·클래스명은 변경 불필요

코드 내부 상태 이유
resultFaction, faction: (JS 변수) 유지 내부 로직 변수 — 사용자에게 노출 안 됨. 변경 시 버그 위험
.faction-chip, .faction-claude (CSS 클래스) 유지 스타일 변수 — 사용자에게 노출 안 됨
affiliate_card_click 이벤트 파라미터 faction: 유지 GA4 분석 데이터 — 바꾸면 히스토리 단절
URL: ai-faction-quiz.vercel.app 유지 SEO 페이지 랭킹 연결됨 — 변경 시 트래픽 손실
메타 keywords: "AI 진영 테스트, AI faction quiz" 유지 허용 SEO 유입용 — 검색 트래픽 확보 목적으로 병기 가능
💡 요약: 사용자가 읽는 텍스트(제목, 버튼, 카피, SNS 글)에는 타입/Type. 코드 내부 변수·URL에는 faction 유지. 두 세계를 분리해서 생각하면 됨.
